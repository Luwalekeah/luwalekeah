# luwalekeah

The GitHub profile README for `Luwalekeah`. This repo renders at github.com/Luwalekeah.

It is a presentation surface, not an application. There is no build, no test, and no deploy. `README.md` is the product.

## Layout

- `README.md` the profile itself
- `assets/` SVG headers and fonts, generated
- `scripts/` generators for the SVG assets
- `.github/workflows/snake.yml` the contribution snake animation

## Deliberately different from every other repo here

There is no `REVIEW.md` and no `lessons.md`. A five-pass security review on a profile README is noise, and noise is what makes review policies get ignored elsewhere. If this repo ever gains real code, add them then.

## Things Claude gets wrong here

- **Editing `assets/*.svg` by hand.** They are generated by `scripts/`. Edit the generator.
- **Adding an external image or badge service without checking it.** Every third-party URL in this README is a request made from a page representing Daniel professionally. A dead service renders a broken image on the profile.
- **Rewriting the voice.** The README is first person and deliberately plain. It is not marketing copy.
- **Claiming a skill or role that is not accurate.** This is a public professional profile linked from a resume.

## Content rules

- Facts stay current. Employer, role, and stack claims must be true today.
- Copy follows the Luwah writing standard: short sentences, active voice, no em dashes, no semicolons, no hype words.
- Links resolve. Check them rather than assuming.
